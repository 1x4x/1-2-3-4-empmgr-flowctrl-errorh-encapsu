# 🧠 Walter Practises

A collection of C# school exercises and Kattis practice solutions covering core programming topics such as employee management, flow control, exception handling, encapsulation, and basic algorithm challenges.

## ✨ Included exercises

### 🏫 School exercises

1. 👨‍💼 Employee Manager
2. 🔁 Flow Control
3. ⚠️ Error Handling
4. 🔒 Encapsulation

### 🧮 Kattis solutions

1. 🧪 FizzBuzz
2. 🔢 Maximum Number
3. 🔀 Sort Two Numbers

## 📁 Project overview

This repository contains multiple small C# programs organized by topic. The main entry point in `Program.cs` allows you to select which exercise to run by uncommenting the desired project.

## 🧩 Main files

- `Program.cs` — main runner for selecting exercises
- `school/` — school assignment solutions
- `kattis/` — Kattis challenge implementations
- `Interface/` — shared interface definitions
- `numbers.txt` — data file used by some exercises

## ▶️ How to run

Open the solution in Visual Studio or another C# IDE and run the project. If needed, uncomment the exercise in `Program.cs` before starting.

Example:

```csharp
runExercise(Exercise.Encapsulation);
```
